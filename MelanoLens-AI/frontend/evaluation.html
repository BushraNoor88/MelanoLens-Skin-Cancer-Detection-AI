How the numbers are computed

  • Mask metrics (Dice, IoU, precision, recall, F1, Boundary F1) compare a filled candidate mask with the reference mask. The candidate mask comes from the contour-selection rule you chose.
  • Edge-map F1 compares raw edge pixels with the boundary of the reference mask using a pixel tolerance. It does not need a contour, but background edges lower it.
  • Results on one image are a single observation, not proof that enhancement helps or hurts in general.
